# Z3805A_rev.D_Samsung
Z3805A_rev.D(Samsung/Furuno GT-8031B version) Backup
 Ref&SLR：-rev.D：Z3805-68003 (5NV00GP),  -rev.C：Z3805A-68001 (6E901C3  3627)

Upon examining the binary editor, I was perplexed to find that my Rev.D and Rev.C files, as well as several Rev.C files found online, were all subtly different. Rev.C appears to be largely identical to the 58503A version (only the internal version differs? Z3805A/Z3801A ⇒ 58503). While the difference between Rev.D and Rev.C is clear (difference in GPS module/Furuno vs. OncoreVP), the other differences might indicate the possibility of derivative versions beyond what is publicly available information (though it could simply be a read error). Furthermore, the Z3805A version has slightly more code than the Z3801A version, while the total number of messages in the Z3805A version seems to be reduced. There were three different model codes: "Z3801A," "Z3805A," and "58503."

The MODEL # entries in the rev.D firmware, which appear to be related to GPS modules, include FURUNO GT-80, GT-77, and GT-74, and seem to correspond to these. The corresponding MODEL # entries in the rev.C firmware appear to be blank.
